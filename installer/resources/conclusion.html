Clipboard2 is ready

Look for the clipboard icon in the menu bar.

⇧⌘VOpen Clipboard2
⌥⌘KActions on selected text
⌥⇧⌘2Capture text from the screen
⌥⇧⌘VPaste as text — even from a screenshot
⌘1–⌘9Paste a quick slot (in Clipboard2)

One more step: Clipboard2 opens a short permissions checklist. Allow Accessibility so it can paste for you; Screen Recording is only needed for capturing text from the screen.

You can change every shortcut in Clipboard2 → Settings.
